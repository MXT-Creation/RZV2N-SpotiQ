Place your compiled DRP-AI model artefacts here before building with bitbake:

    deploy.so      - compiled DRP-AI kernel (generated by drp-ai-tvm compiler)
    deploy.params  - DRP-AI parameter binary
    deploy.json    - model meta-data / configuration JSON
    labels.txt     - one gesture label per line (must match NUM_CLASS in define.h)

These files are installed on the target at:

    /opt/hand_gesture_recognition/hand_yolov3_onnx/deploy.so
    /opt/hand_gesture_recognition/hand_yolov3_onnx/deploy.params
    /opt/hand_gesture_recognition/hand_yolov3_onnx/deploy.json
    /opt/hand_gesture_recognition/labels.txt

The ROS2 node's 'model_dir' parameter must point to the directory containing
deploy.so / deploy.params / deploy.json, which defaults to:
    /opt/hand_gesture_recognition/hand_yolov3_onnx

To generate these files run the DRP-AI TVM compiler on your ONNX model:
    https://github.com/renesas-rz/rzv_drp-ai_tvm
